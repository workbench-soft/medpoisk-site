# medpoisk-site

The built web page of МедПоиск at `medpoisk.workbench-soft.com`, served by
GitHub Pages. Don't edit it here.

- **Source** the private
  [`workbench-soft/medpoisk`](https://github.com/workbench-soft/medpoisk)
  holds the Expo app, the search Worker and the docs.
- **Deploy** `mise run deploy` of `medpoisk`, from the PC or its Web workflow
  once Checks pass, builds the page and pushes it here. Each deploy replaces
  every file except this README.
- **Why two repos** the org is on the free plan, and GitHub Pages serves a free
  org only from a public repo. The source stays private.
